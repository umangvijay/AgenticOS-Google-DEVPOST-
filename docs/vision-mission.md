# Vision and mission

## Vision

AgentOS is a workspace where describing the outcome is enough. If a tool is missing, the system builds it (OpenAPI HTTP tools, sketched HTTP tools, or origin-locked browser tools), tests it live, registers it, and uses it — in the same run.

## Mission

- Plan work with a live model, not canned scripts.
- Build MCP tools for **any** HTTP API (OpenAPI, docs URL, or description) and for websites that have no API (Playwright, origin-locked).
- Execute with real I/O: HTTP, site health, email, browser, artifacts, resumes.
- Keep secrets in an encrypted vault. Let people bring their own Gemini key.
- Show the run as a conversation, with a DAG when you want the graph.

## What we will not do

We will not pretend a hardcoded Stripe/Slack list is "every integration." Examples in the UI are examples. The factory is the product. We will not solve CAPTCHA, OTP, or MFA, and we will not store a Google mailbox password.
